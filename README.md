# Reservierungssystem – Android-App

App des Reservierungssystems von **ufercode studio** für Android-Tablets und -Handys.
Dieses Repository enthält ausschließlich die fertige App (`Reservierungssystem.apk`) und die
Versionsinfo (`version.json`) – **keinen Quellcode**.

**Herunterladen:** <https://ufercode.de/downloadreservierungssystem>
(oder direkt: [Reservierungssystem.apk](https://github.com/Congamer69/ufercode-reservierungssystem-apk/raw/main/Reservierungssystem.apk))

Updates: in der App unter *Einstellungen › App › Auf Updates prüfen* – oder diese Seite erneut öffnen.
Die Datei lässt sich über die bestehende Installation installieren, alle Daten bleiben erhalten.
